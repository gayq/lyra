## features
- nice ui
- thousands of games aggregated from multiple sources
- free anime streaming
- cloud syncing
- functional chrome extensions support
- very efficient
- private by design

## self-hosting

normal
```bash
# clone
git clone https://github.com/gayq/lyra

# run setup file
cd lyra
bash setup.sh
```

static
```bash
# clone
git clone https://github.com/gayq/lyra

# run setup file
cd lyra
bun i
bun build:static

# built files are located in dist-static
```

## local development
```bash
bun i
bun dev
```
